# Matte OS · Simple-study release · 2026-11-16

## Owner intent and scope
Students should navigate as easily as choosing a show: see four large choices (Matte/Svenska/Engelska/Spela), start without setup, always find the profile switch at the top right, and never wonder where they are. This is a presentation and route simplification, **not** a new account system or an adjustment to school grades or answer assessment.

## Critical paths
| Start | One-tap outcome | Escape or return |
| --- | --- | --- |
| Matte OS | Four large colored study tiles, persistent five-way footer | Start tab; top profile chooser |
| Maths tile | Five real math questions immediately | In-focus Back; profile button remains accessible |
| Svenska | Reading recommendation and three expandable level shelves | Bottom Start, Matte, Svenska, Engelska, Spela |
| English | English reading recommendation, levels; text details | Same five destinations |
| Spela | Three subject choices (SV/EN/Matte), then self or together | Five-way footer, Home icon, profile chooser |
| Play: together | Selected material visible without opening an advanced panel | Return Home, session saved, no silent overwrite |
| Profiles | Existing Åk 8, Åk 9 and Jokers, distinguishable by name/initials | Switching grade is in-place in Together; separate grade/guest data remain unmerged |

Additional options: Cup / remote Live, multiplication tables, study techniques, restprov, formula posters, settings and guest management remain reachable through descriptive expandable panels, not removed.

## Technical boundaries
- Root maths: existing `matteos.v5` grade storage; existing `profile-chooser.js` in main and focus screens.
- Learning: existing `matteos.larande.v1` and workshop-specific grade data; header profile chooser remains active; reading shelves contain the full preexisting anthology plus the eleven original stories.
- Together: existing `MOTogether` guest model, existing synthetic guest defaults and separate group session store. Group sessions **never** write grade assessment results. Switching during a group prompts before leaving the active view; a stored session remains resumable.
- No SQL/database schema, Supabase auth, payments or remote student tracking change.
- Service worker scopes stay separate; root and Learning precache their current UI bundles and the shared CSS.
- Basic accessibility: textual labels on all five destinations, 44px+ touch targets, selected `aria-current` or `aria-pressed`, visible focus, reduced-motion support; keyboard Escape for Together profile overlay.

## Release gates / checks
1. Unit/content checks in `.github/workflows/matte-qa.yml` confirm all existing curriculum, reading, assessment, UI copy and offline parity.
2. Mobile browser scripts validate 320/390px, grade8/grade9 separation, real tasks, Together group/solo/resume, cross-module navigation, night-mode and no unhandled errors; new `tests/netflix-simple-e2e.js` covers core simplified route.
3. Cross-engine WebKit and Firefox tests must pass before merging.
4. After CI success and merge into `main`, public GitHub Pages HTML/script and rendered routes must show build 6.8.0-simple (root), 4.6.0-simple (Learning), the subject chooser and profile switch in Together.
5. Unverified until physical-device trials: on-device Safari offline navigation (especially PWA update mid-exercise), first-time behavior of a real five-year-old, educational effect on reading retention. Do not label those proven.

## Rollback
Revert the exact single squash merge via GitHub; restore previous JS/CSS/HTML and service-worker version together. Do not clear any localStorage, IndexedDB, or profiles. Because cache versions are independent, both roots will self-rebuild their offline caches on reinstall; if a service-worker update is still pending, reload outside an active question. Preserve and test one synthetic grade8/grade9 snapshot and resumable Together session before and after.
