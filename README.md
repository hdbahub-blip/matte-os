# Matte OS

Statisk, offline-first matteapp för årskurs 8 och 9.

- Ingen backend krävs.
- Elevprogression sparas lokalt i webbläsaren.
- Inga personnamn finns i den publicerade versionen.
- GitHub Pages används endast för att leverera appkoden.

På iPhone/iPad: öppna GitHub Pages-länken i Safari → Dela → Lägg till på hemskärmen.
